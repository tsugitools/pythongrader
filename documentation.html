PythonGrader

Edit student.py, optionally provide standard input, then Run to try your program. When the output looks right, press Grade.

Grade is disabled until you Run the current source (so stale code is never scored).

Python runs entirely in your browser via Pyodide. Infinite loops time out and restart the runtime automatically.

Instructors: use Settings to pick a built-in assignment, or Edit to change the placement copy.
